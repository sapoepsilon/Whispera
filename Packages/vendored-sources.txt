#   git  <dir> <upstream git URL> <commit>
#   zip  <dir> <release asset URL> <sha256 of the asset>
#   rm   <dir> <path or glob, relative to the package root>   paths deleted when vendoring
#   local <dir> <exact path>   a file changed or added here on purpose (see VENDORED.md)
#
# Package.swift / Package@swift-*.swift files are expected to differ (local path deps, trimmed
# targets) and are diffed separately. Everything else must be byte-identical to upstream,
# except the files a `local` line names.
